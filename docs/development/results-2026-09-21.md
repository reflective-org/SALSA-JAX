## Preliminary CPU leaf timing

Final recorded run: 1000 repetitions per trial, five alternating-order trials,
1734 coefficients per batch. Fortran uses warmed internal wall time; JAX uses
synchronized compiled calls. Compilation, input transfer, startup and I/O are
excluded from warm timings and documented separately.

| Measurement | Result |
|---|---:|
| Median Fortran batch wall time | 33.133 µs |
| Median JAX batch wall time | 36.960 µs |
| Fortran/JAX wall-time ratio | 0.896 |
| JAX lowering/compilation | 0.0400 s |

JAX is about 12% slower for this batch on this machine. Small-batch dispatch
overhead is included; thread allocation is not normalized. This is a preliminary
single-machine measurement, not a controlled single-thread result or a forecast
of full-model/ensemble performance. Earlier trials varied, so use raw samples
rather than treating the median as a hardware constant.
